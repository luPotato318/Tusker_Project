# PIEM 2.2.0 — Apex Evolution Release

Data: 27/08/2026

## Principais mudanças

- Refatoração visual com glassmorphism, gradientes e microanimações.
- Separação dos portais de login de estudantes e administradores.
- Primeira versão do painel administrativo para usuários e oficinas.
- Recomendador de oficinas e tarefas práticas no Tutor PIEM.
- Suporte a PostgreSQL, documentação Supabase e ponte PHP.
- Versionamento integrado à aplicação.
